# FPH Transport — Landing Page

Landing page pentru **FPH Transport**: transport de mărfuri grele, echipamente și vehicule din Marea Britanie în România și Republica Moldova.

Site static (HTML + CSS + JS, fără build), în stil „Liquid Glass”.

## Structură

```
index.html              pagina completă (stiluri și scripturi incluse)
assets/logo.svg         logo-ul vectorial
assets/logo-original.png  logo-ul original
```

## Rulare locală

Deschide `index.html` în browser, sau pornește un server local:

```bash
python3 -m http.server 8765
```

apoi intră pe http://localhost:8765

## Publicare pe GitHub Pages

1. Încarcă fișierele într-un repository pe GitHub.
2. Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Site-ul va fi disponibil la `https://<utilizator>.github.io/<repository>/`.
